## Guias

# Traga seus ícones para casa

Você não precisa migrar tudo de uma vez. Faça a troca por ícone ou por funcionalidade.

### 1. Encontre o equivalente visual

Pesquise no [explorador de ícones](../../icons), compare as variantes e anote o ID exato `@colecao/icone`. Nomes parecidos nem sempre representam o mesmo desenho.

### 2. Inicialize uma vez e adicione o escolhido

```bash
npx @rocketicons/cli init
npx @rocketicons/cli add @lu/lu-search
```

### 3. Troque o import do pacote

```tsx
// Antes
import { LuSearch } from "react-icons/lu";

// Depois
import LuSearch from "@/ri/icons/lu-search";
```

Ajuste estilos e rótulos de acessibilidade quando necessário. Depois, compare o resultado renderizado em todos os tamanhos e estados usados na interface.

### 4. Remova a dependência antiga por último

Procure imports restantes no repositório. Remova o pacote anterior apenas quando nenhum deles existir e valide seu build normal de produção, web ou nativo.

Rocketicons mantém utilitários compartilhados instalados, mas os componentes selecionados ficam no seu código. A vantagem é estrutural: sua aplicação não importa milhares de exports que nunca usa nem depende de tree-shaking para descartá-los.
