## Guias

# Um plano de voo claro para agentes de código

Agentes trabalham melhor quando a descoberta é enxuta, os comandos são exatos e toda alteração tem um resultado observável. Rocketicons oferece uma CLI e um servidor MCP local apoiados no mesmo catálogo e nas mesmas operações de projeto.

O pacote MCP está disponível no npm como `@rocketicons/mcp`.

### Configure um cliente MCP

O Rocketicons roda localmente via stdio com `npx -y @rocketicons/mcp`. Use Node.js 20 ou mais recente, com `node` e `npx` disponíveis para o cliente. O cliente inicia o servidor; não é necessário manter outro terminal aberto nem instalar o pacote globalmente. A primeira execução precisa de internet para baixar o pacote. A busca usa o Algolia quando disponível e recorre ao catálogo incluído no pacote quando estiver offline.

Em qualquer cliente com suporte a MCP local via stdio, defina o comando como `npx` e os argumentos como `["-y", "@rocketicons/mcp"]`. Clientes que aceitam apenas servidores HTTP remotos não podem usar esse comando diretamente. A busca padrão não exige chave de API. As ferramentas de projeto recebem um `project_path` absoluto na chamada, portanto ele não faz parte da configuração do servidor.

Adicione estas entradas aos arquivos existentes sem remover outros servidores. Depois de salvar, reinicie ou reconecte o servidor MCP no cliente. Se o cliente não encontrar `npx`, use o caminho absoluto retornado por `command -v npx` e confira se o Node.js está disponível no ambiente do cliente.

#### Codex

Adicione a `.codex/config.toml` em um projeto confiável ou a `~/.codex/config.toml` para usar globalmente:

```toml
[mcp_servers.rocketicons]
command = "npx"
args = ["-y", "@rocketicons/mcp"]
startup_timeout_sec = 60
```

O limite de 60 segundos dá mais tempo para o primeiro download. Reinicie o Codex e use `/mcp` para conferir a conexão. Consulte a [documentação MCP do Codex](https://developers.openai.com/codex/mcp).

#### Cursor

Adicione a `.cursor/mcp.json` no projeto ou a `~/.cursor/mcp.json` para usar globalmente:

```json
{
  "mcpServers": {
    "rocketicons": {
      "command": "npx",
      "args": ["-y", "@rocketicons/mcp"]
    }
  }
}
```

Confira se o Rocketicons está habilitado e conectado nas configurações MCP do Cursor. Consulte a [documentação MCP do Cursor](https://cursor.com/docs/mcp).

#### Claude Code

Adicione diretamente a `.mcp.json` na raiz do projeto:

```json
{
  "mcpServers": {
    "rocketicons": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@rocketicons/mcp"]
    }
  }
}
```

Como alternativa, execute no diretório do projeto:

```bash
claude mcp add --scope project --transport stdio rocketicons -- npx -y @rocketicons/mcp
```

Use `--scope user` para disponibilizar em todos os seus projetos. Reinicie o Claude Code, aprove o servidor do projeto quando solicitado e use `/mcp` para conferir a conexão. Estas instruções são para o Claude Code. Consulte a [documentação MCP do Claude Code](https://code.claude.com/docs/en/mcp).

#### Confira a conexão

Peça ao agente:

> Use o MCP do Rocketicons para encontrar cinco ícones de comida da mesma coleção e compará-los visualmente. Não altere arquivos do projeto.

A busca e a inspeção de SVG não exigem inicializar o projeto. Para instalar componentes depois, peça ao agente que inspecione o projeto e use `plan_icons` antes de `apply_icons`.

### Encontre e adicione um ícone

1. Pesquise com `npx rocketicons search calendar --collection fi --json` ou com a ferramenta MCP `recommend_icons`, informando o caminho do projeto, a intenção e o arquivo de origem.
2. Confira o ID exato `@colecao/id-do-icone`, a licença e o recurso SVG.
3. Reutilize um arquivo em `src/ri/icons` quando ele já resolver a necessidade.
4. Faça um dry run de `add` na CLI ou use `plan_icons` no MCP para revisar arquivos e dependências antes de `apply_icons`.
5. Use o import relativo ao arquivo de origem e execute `doctor`.

### Adicione um pequeno conjunto

A CLI aceita vários IDs exatos. Mantenha a alteração fácil de auditar:

```bash
npx rocketicons add @lu/lu-search @lu/lu-circle-check --dry-run --json
npx rocketicons add @lu/lu-search @lu/lu-circle-check
```

Para usar o MCP, configure o cliente para iniciar `npx -y rocketicons mcp` via stdio. O comando dedicado `npx -y @rocketicons/mcp` também funciona. Chame `recommend_icons` e depois `plan_icons` com os IDs exatos e `from_file`; revise o plano e passe seu `planId` para `apply_icons`. A aplicação configura o projeto, adiciona os ícones e verifica o resultado. A busca usa um índice local quando o Algolia não estiver disponível.

Em projetos web com Tailwind CSS 4, o plano inclui a alteração no CSS que registra `@rocketicons/tailwind`. Confira o resultado de `doctor` após aplicar: os dados em `styling` e os problemas informam se falta importar o CSS, registrar o plugin ou integrar Vite/PostCSS. Passe `stylesheet_path` para o plano e para a aplicação quando houver vários arquivos CSS ativos com Tailwind.

Depois de adicionar um ícone, você pode editar o componente gerado em `src/ri/icons/`. O `doctor` informa alterações de conteúdo como customizações, e o `recommend_icons` pode sugerir reutilizar esse componente. O `plan_icons` mostra o arquivo em `preservedIcons`; `apply_icons` e `add_icons` não o sobrescrevem. Alterações apenas de formatação não o marcam como customizado. O `remove_icons` protege arquivos customizados contra exclusão.

### Use SVG em um site HTML simples

Para um site sem React, chame `search_icons` e `get_icon` no MCP para escolher um ID exato e conferir a licença. Chame `get_icon_svg` com esse ID para receber o SVG completo. Insira o código no HTML ou salve-o como arquivo `.svg`. Esse caminho dispensa `init_project` e a configuração do Rocketicons no projeto.

### Declare os estados no estilo

```tsx
<RcRocketIcon className="icon-sky-500-lg dark:icon-white-lg hover:icon-sky-600-lg" />
```

### Confira a alteração

```bash
npx rocketicons doctor --json
git status --short src/ri rocketicons.json tsconfig.json package.json package-lock.json
```

Relate cada arquivo alterado. Execute a checagem de tipos e o build web ou nativo relevante do próprio projeto antes de concluir a tarefa.

### Prompt para reutilizar

> Use Rocketicons para os ícones deste projeto. Reutilize um componente adequado em `src/ri/icons` quando possível. Caso contrário, encontre um ID exato `@colecao/id-do-icone`, confira a licença e o SVG, planeje as alterações, aplique o plano revisado, use um import relativo ao arquivo de origem e informe cada arquivo alterado. Não instale nem importe uma coleção completa de ícones.

Para uma referência compacta e legível por máquinas, indique [`/llms.txt`](/llms.txt) ao agente.
