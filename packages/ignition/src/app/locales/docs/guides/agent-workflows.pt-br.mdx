## Guias

# Um plano de voo claro para agentes de código

Agentes trabalham melhor quando a descoberta é enxuta, os comandos são exatos e toda alteração tem um resultado observável. Rocketicons oferece uma CLI e um servidor MCP local apoiados no mesmo catálogo e nas mesmas operações de projeto.

O pacote MCP e os novos comandos da CLI estão disponíveis no build do repositório; a publicação no npm ainda está pendente.

### Encontre e adicione um ícone

1. Pesquise com `npx rocketicons search calendar --collection fi --json` ou com a ferramenta MCP `recommend_icons`, informando o caminho do projeto, a intenção e o arquivo de origem.
2. Confira o ID exato `@colecao/id-do-icone`, a licença e o recurso SVG.
3. Reutilize um arquivo em `src/ri/icons` quando ele já resolver a necessidade.
4. Faça um dry run de `add` na CLI ou use `plan_icons` no MCP para revisar arquivos e dependências antes de `apply_icons`.
5. Use o import relativo ao arquivo de origem e execute `doctor`.

### Adicione um pequeno conjunto

A CLI aceita vários IDs exatos. Mantenha a alteração fácil de auditar:

```bash
npx rocketicons add @lu/lu-search @lu/lu-circle-check --dry-run --json
npx rocketicons add @lu/lu-search @lu/lu-circle-check
```

Para usar o MCP, configure o cliente para iniciar `npx -y rocketicons mcp` via stdio. O comando dedicado `npx -y @rocketicons/mcp` também funciona. Chame `recommend_icons` e depois `plan_icons` com os IDs exatos e `from_file`; revise o plano e passe seu `planId` para `apply_icons`. A aplicação configura o projeto, adiciona os ícones e verifica o resultado. A busca usa um índice local quando o Algolia não estiver disponível.

### Use SVG em um site HTML simples

Para um site sem React, chame `search_icons` e `get_icon` no MCP para escolher um ID exato e conferir a licença. Chame `get_icon_svg` com esse ID para receber o SVG completo. Insira o código no HTML ou salve-o como arquivo `.svg`. Esse caminho dispensa `init_project` e a configuração do Rocketicons no projeto.

### Declare os estados no estilo

```tsx
<RcRocketIcon className="icon-sky-500-lg dark:icon-white-lg hover:icon-sky-600-lg" />
```

### Confira a alteração

```bash
npx rocketicons doctor --json
git status --short src/ri rocketicons.json tsconfig.json package.json package-lock.json
```

Relate cada arquivo alterado. Execute a checagem de tipos e o build web ou nativo relevante do próprio projeto antes de concluir a tarefa.

### Prompt para reutilizar

> Use Rocketicons para os ícones deste projeto. Reutilize um componente adequado em `src/ri/icons` quando possível. Caso contrário, encontre um ID exato `@colecao/id-do-icone`, confira a licença e o SVG, planeje as alterações, aplique o plano revisado, use um import relativo ao arquivo de origem e informe cada arquivo alterado. Não instale nem importe uma coleção completa de ícones.

Para uma referência compacta e legível por máquinas, indique [`/llms.txt`](/llms.txt) ao agente.
