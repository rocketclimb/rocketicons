## Comece por aqui

# Adicione seu primeiro ícone

Com Rocketicons, você procura entre milhares de ícones open source e adiciona apenas os componentes que seu projeto usa. A CLI grava esses arquivos no seu código: sua aplicação não importa uma coleção inteira nem depende de tree-shaking para fazer os ícones não usados sumirem.

### Antes de decolar

A CLI atual espera um projeto **TypeScript** existente, em React ou React Native, com um arquivo `tsconfig.json`. Execute os comandos na raiz desse projeto.

### 1. Inicialize o Rocketicons

```bash
npx rocketicons init
```

A inicialização cria:

```text
src/ri/
├── core/
│   ├── index.tsx
│   └── index.native.tsx
└── icons/
```

Ela também adiciona o alias `@/ri/*` ao `tsconfig.json` e instala `@rocketicons/utils` e `@rocketicons/tailwind` pelo npm. Essas são pequenas dependências compartilhadas usadas pelos componentes gerados e pela integração com Tailwind.

### 2. Confira a estilização com Tailwind

Em um projeto web com Tailwind CSS 4, a inicialização encontra o arquivo CSS ativo com `@import "tailwindcss"` e adiciona automaticamente o plugin do Rocketicons:

```css
@import "tailwindcss";
@plugin "@rocketicons/tailwind";
```

Execute `npx rocketicons doctor --json` para conferir a versão do Tailwind, o carregamento do CSS, o registro do plugin e a integração com Vite ou PostCSS. Se houver mais de um arquivo CSS ativo com Tailwind, passe `--stylesheet-path src/caminho/estilos.css` ao comando `init`. O dry run mostra qual arquivo CSS será alterado antes da escrita.

### 3. Encontre um ícone

Use o [explorador de ícones](../../icons) para escolher uma coleção e o ID exato. Por exemplo, o foguete do próprio Rocketicons é `@rc/rc-rocket-icon`.

### 4. Adicione ao projeto

```bash
npx rocketicons add @rc/rc-rocket-icon
```

A CLI grava `src/ri/icons/rc-rocket-icon.tsx`. Importe o componente do seu próprio código:

```tsx
import RcRocketIcon from "@/ri/icons/rc-rocket-icon";

export function BotaoDeLancamento() {
  return <RcRocketIcon className="icon-sky-500-lg" />;
}
```

Esse é o plano de voo completo: encontre, adicione e importe. Continue em [Adicionando Ícones](./adicionando-icones) para ver instalações repetidas e verificação, ou abra os [guias rápidos por framework](./guias-rapidos-frameworks).

> O build da CLI no repositório gera TSX ou JSX no diretório fixo `src/ri`, aceita vários ícones exatos por comando e detecta o gerenciador de pacotes do projeto. Use `--dry-run` e `--json` para conferir as alterações. Esses novos comandos aguardam a próxima publicação no npm.
