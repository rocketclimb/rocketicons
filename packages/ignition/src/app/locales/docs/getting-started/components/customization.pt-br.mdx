### Customização

<RocketIconsTextDefault /> pode ser facilmente personalizado em cada uso usando classes do
<SiTailwindcss className="-mt-1" /> **Tailwind** para combinar com o design de sua aplicação.

Você também pode criar componentes **React** <SiReact className="-mt-1 icon-sky-800" /> em seu projeto
que estendem o componente padrão e adicionam seus estilos personalizados.

Novamente, sempre usando as classes do **Tailwind** <SiTailwindcss className="-mt-1" />.

## Customização Global

No Tailwind CSS v4 a configuração mora no CSS, então customizar ícones é só declarar valores na sua folha de estilos global.

#### 1. Adicionando suas próprias cores

Defina uma variável CSS dentro de um bloco `@theme` — o plugin gera uma classe `icon-<nome>-<tamanho>` para ela automaticamente, e o `fill`/`stroke` sempre passa por `var(--color-<nome>)`, então dark mode e troca de tema em runtime "simplesmente funcionam":

```css
/* @tabContent(globals.css) */
@import "tailwindcss";
@plugin "rocketicons/tailwind";

@theme {
  --color-brand: oklch(0.6 0.2 30);
  --color-brand-light: oklch(0.8 0.15 30);
}

/* Agora você pode usar:
   <RcIcon className="icon-brand-base" />
   <RcIcon className="icon-brand-light-lg.icon-filled" />
*/
/* @endTabContent */
```

Isto é novidade no v4. A versão anterior (v3) do plugin "embutia" os valores das cores no momento de inicialização, então sobrescritas da paleta padrão do Tailwind eram ignoradas. Com v4 toda cor passa por `var(--color-*)` — sobrescrever `--color-sky-500` (ou qualquer outra padrão) atualiza automaticamente cada `icon-sky-*` no seu output.

#### 2. Redefinindo o tema dos ícones

Se você precisa alterar os padrões do plugin — tamanho base, estilo base, escala de tamanhos — passe um bloco `components.icon` como opções do plugin no momento de registrá-lo:

```css
/* @tabContent(globals.css) */
@import "tailwindcss";

@plugin "rocketicons/tailwind" {
  components: {
    icon: {
      default: "sky-500-base",
      baseStyle: "p-0 inline-block",
      variants: {
        filled: "",
        outlined: "",
      },
      sizes: {
        base: "size-5",
      },
    },
  },
}
/* @endTabContent */
```

> Ao redefinir o tema por completo, certifique-se de definir todas as propriedades e que o `default` referencie um tamanho que realmente exista.

O nosso tema padrão é assim:

```js filename=tailwind/theme.js
{
  default: "sky-500-base",
  baseStyle: "p-0 inline-block",
  variants: {
    filled: "",
    outlined: "",
  },
  sizes: {
    xs: "size-2",
    sm: "size-4",
    base: "size-5",
    lg: "size-6",
    xl: "size-7",
    "2xl": "size-8",
    "3xl": "size-9",
    "4xl": "size-10",
    "5xl": "size-11",
    "6xl": "size-12",
    "7xl": "size-14",
  },
}
```

Você pode sobrescrever:

- `default` — a classe padrão (cor + tamanho)
- `baseStyle` — utilitários aplicados a todo ícone
- `variants` — regras adicionais para `filled` / `outlined`
- `sizes` — escala usada para gerar `icon-xs`, `icon-sm`, …

Cores não fazem parte do tema do plugin — elas vêm direto das suas declarações `@theme { --color-* }` e da paleta padrão do Tailwind. Qualquer `--color-*` presente no seu CSS gerado funciona como `icon-<nome>-<tamanho>`.
