### Customization

<RocketIconsTextDefault /> can be easily customized on every use using <SiTailwindcss className="-mt-1" /> **Tailwind**
classes to match your application's design.

You can also create <SiReact className="-mt-1 icon-sky-800" /> **React** components on your project which extends the default component and add your custom styles.

Again, always using the <SiTailwindcss className="-mt-1" /> **Tailwind** classes.

### Global customization

In Tailwind CSS v4 the configuration lives in CSS, so customizing icons is just a matter of declaring values in your global stylesheet.

#### 1. Adding your own colors

Define a CSS variable in a `@theme` block — the plugin emits an `icon-<name>-<size>` class for it automatically, and the `fill`/`stroke` always resolve through `var(--color-<name>)` so dark mode and runtime theming "just work":

```css
/* @tabContent(globals.css) */
@import "tailwindcss";
@plugin "rocketicons/tailwind";

@theme {
  --color-brand: oklch(0.6 0.2 30);
  --color-brand-light: oklch(0.8 0.15 30);
}

/* Now you can use:
   <RcIcon className="icon-brand-base" />
   <RcIcon className="icon-brand-light-lg.icon-filled" />
*/
/* @endTabContent */
```

This is new in v4. The previous (v3) version of the plugin baked color values at plugin-init time, so user overrides of Tailwind's default palette were ignored. With v4 every color resolves through `var(--color-*)` — overriding `--color-sky-500` (or any other default) automatically updates every `icon-sky-*` class in your output.

#### 2. Redefining the icon theme

If you need to change the plugin's defaults — base size, base style, the available size scale — pass a `components.icon` block as plugin options when registering it:

```css
/* @tabContent(globals.css) */
@import "tailwindcss";

@plugin "rocketicons/tailwind" {
  components: {
    icon: {
      default: "sky-500-base",
      baseStyle: "p-0 inline-block",
      variants: {
        filled: "",
        outlined: "",
      },
      sizes: {
        base: "size-5",
      },
    },
  },
}
/* @endTabContent */
```

> When fully redefining the theme, make sure every property is set and that `default` references a size you actually defined.

This is what the default theme looks like:

```js filename=tailwind/theme.js
{
  default: "sky-500-base",
  baseStyle: "p-0 inline-block",
  variants: {
    filled: "",
    outlined: "",
  },
  sizes: {
    xs: "size-2",
    sm: "size-4",
    base: "size-5",
    lg: "size-6",
    xl: "size-7",
    "2xl": "size-8",
    "3xl": "size-9",
    "4xl": "size-10",
    "5xl": "size-11",
    "6xl": "size-12",
    "7xl": "size-14",
  },
}
```

You can override:

- `default` — the default class (color + size)
- `baseStyle` — utilities applied to every icon
- `variants` — additional rules for `filled` / `outlined`
- `sizes` — the size scale used to generate `icon-xs`, `icon-sm`, …

Colors are not part of the plugin's theme — they come straight from your `@theme { --color-* }` declarations and from Tailwind's default palette. Any `--color-*` that exists in your generated CSS works as `icon-<name>-<size>`.
