### Instalação

<RocketIconsTextDefault /> requer **Tailwind CSS v4 ou superior** e **Node.js 20+**. Se você ainda usa o Tailwind CSS v3, fixe `rocketicons@<0.3.0` até concluir a migração.

Instale <RocketIconsTextDefault /> junto com o Tailwind CSS:

```bash
npm install rocketicons tailwindcss @tailwindcss/postcss
```

ou

```bash
pnpm add rocketicons tailwindcss @tailwindcss/postcss
```

ou

```bash
yarn add rocketicons tailwindcss @tailwindcss/postcss
```

ou até mesmo

```bash
bun add rocketicons tailwindcss @tailwindcss/postcss
```

Boom!

Agora que você instalou <RocketIconsTextDefault /> no seu projeto, você pode prosseguir para a configuração.
