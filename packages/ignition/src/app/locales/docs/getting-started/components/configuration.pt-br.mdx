### Configuração

O Tailwind CSS v4 adota uma configuração baseada em CSS. Não existe mais o `tailwind.config.js` — você registra o plugin do <RocketIconsTextDefault /> diretamente na sua folha de estilos global, usando a diretiva `@plugin`.

No arquivo CSS importado na raiz do seu app (normalmente `globals.css` ou `app.css`):

```css
/* @tabContent(globals.css) */
@import "tailwindcss";
@plugin "rocketicons/tailwind";
/* @endTabContent */
```

Pronto — o Tailwind v4 resolve o plugin a partir do `node_modules` e emite os utilitários de ícones automaticamente.

#### Configuração do PostCSS

Se seu projeto ainda não tem o PostCSS configurado para o Tailwind v4, adicione:

```js
// @tabContent(postcss.config.js)
module.exports = {
  plugins: {
    "@tailwindcss/postcss": {}
  }
};
// @endTabContent
// @tabContent(postcss.config.mjs)
export default {
  plugins: {
    "@tailwindcss/postcss": {}
  }
};
// @endTabContent
```

#### Migrando do v3

Se você está atualizando um projeto que já usava `rocketicons` com Tailwind CSS v3, o padrão antigo `tailwind.config.{js,mjs,ts}` com `plugins: [icons]` não é mais necessário — pode remover. Mova qualquer `theme.extend.colors`, `theme.extend.spacing`, etc. para um bloco `@theme { ... }` no seu CSS e o plugin vai consumir automaticamente (mais detalhes em [Customização](./customization)).

Depois disso, você pode usar <RocketIconsTextDefault /> em seu projeto.
