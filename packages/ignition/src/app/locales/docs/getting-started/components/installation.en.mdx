### Installation

<RocketIconsTextDefault /> requires **Tailwind CSS v4 or newer** and **Node.js 20+**. If you're still on Tailwind CSS v3, pin `rocketicons@<0.3.0` until you migrate.

Install <RocketIconsTextDefault /> alongside Tailwind CSS:

```bash
npm install rocketicons tailwindcss @tailwindcss/postcss
```

or

```bash
pnpm add rocketicons tailwindcss @tailwindcss/postcss
```

or

```bash
yarn add rocketicons tailwindcss @tailwindcss/postcss
```

or even

```bash
bun add rocketicons tailwindcss @tailwindcss/postcss
```

Boom!

Now that you have installed <RocketIconsTextDefault /> in your project, you can proceed to the configuration.
