✓Outcome

The shared rocketicons index contains 46,566 icon records and 91 localized documentation records. The static client uses only the public Application ID and Search-only key. The Write key is held only as an encrypted GitHub Actions secret and is consumed by the post-build indexer.

The live index is ready now. Production search will start using it after this branch is merged and the main workflow exports and deploys the updated client bundle to Cloudflare Pages.

↔What changed

Before

The deployed client referenced a historical Algolia application that no longer resolves. Search returned no results, the indexer swallowed failures, per-locale indices duplicated icon records, and an Admin-key-shaped value lived in the server environment schema.

After

CI atomically replaces one locale-aware index, fails closed on missing credentials, validates IDs and record sizes, and keeps indexing credentials out of all browser imports. Search results route using stable icon and document identifiers and stale queries are cleared.

Important implementation files

  • .github/workflows/pages.yml — secure variables, encrypted indexing secret, synchronization gate, and corrected rocketicons.com fallback.
  • packages/ignition/src/algolia-indexer.ts — atomic shared-index synchronization.
  • packages/ignition/src/algolia/records.ts — deterministic records, collision and size validation.
  • packages/ignition/src/env/client.ts — public client configuration only.
  • search-algolia.tsx and search-hits.tsx — locale filtering and stable result routing.
