✓Outcome

The existing GitHub Actions build remains the single build pipeline. After a qualifying pull request passes export verification, Wrangler uploads packages/ignition/out to the existing rocketicons Pages project with the branch alias pr-<number>.

PR #164 received the stable alias https://pr-164.rocketicons.pages.dev. Production remained untouched and continues to deploy only from main.

↔What changed

Before

Pull requests built, tested, and exported the static site, but the only Pages upload was guarded for non-PR runs on main.

After

Same-repository, non-Dependabot pull requests upload the verified export as a preview. The branch alias is added to the Actions job summary, and both Pages deployments use cloudflare/wrangler-action@v4.
