✓Outcome

The consolidated branch refreshes the package versions represented by the old Dependabot PRs, resolves their shared lockfile once, and changes Dependabot so weekly npm updates target develop as one group.

Ionicons remains on v4 intentionally: that dependency is the source for the public “Ionicons 4” catalog. Dependabot major updates for that package are now ignored so a future automated PR cannot silently replace the catalog with v8.

↔What changed

Before

Six PRs targeted main, carried mid-2024 versions, and overlapped a develop branch that had already moved Next.js, React DOM, and react-native-svg forward.

After

Tailwind is 3.4.19 at the root; the generator uses React/React DOM 18.3.1 and react-native-svg 15.15.5; Next.js resolves to 15.5.24 in Ignition; compatible ws lines resolve through 6.2.6, 7.5.13, and 8.21.3.
